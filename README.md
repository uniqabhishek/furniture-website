A handcrafted, minimalist e-commerce and catalog web experience built for **Grain & Joint**, an artisanal solid wood furniture studio. Emphasizes warm organic tones, editorial typography, modular layout systems, and pixel-perfect responsiveness across all viewports.

---

## ✨ Features & Highlights

- **Editorial Aesthetic & Art Direction**: Warm wood-inspired color harmony (`Walnut`, `Oak`, `Linen`, `Paper`) paired with classical typography ([Fraunces](https://fonts.google.com/specimen/Fraunces) and [Work Sans](https://fonts.google.com/specimen/Work+Sans)).
- **Custom CSS Architecture**: Zero heavy frontend frameworks — built with clean, modern CSS Variables, CSS Grid, and Flexbox for maximum rendering speed and 100/100 Lighthouse performance.
- **Product Catalog & Showcase**: Detailed product cards with specifications, material details, dimensions, and craft storytelling.
- **Mobile-First Responsive Layout**: Fluid transitions and layouts adapted seamlessly for smartphones, tablets, and ultra-wide desktop monitors.
- **Micro-Interactions**: Subtle hover states, smooth transitions, and tactile feedback.

---

## 🛠️ Built With

- **HTML5**: Semantic document structure for accessibility (a11y) and SEO optimization.
- **Modern CSS3**:
  - CSS Custom Properties (`--walnut`, `--linen`, `--oak`, `--paper`)
  - CSS Grid & Flexbox layouts
  - Responsive media queries
  - Google Web Fonts integration
- **Vanilla JavaScript**: Lightweight DOM interactions.

## 🚀 Live Preview & Getting Started

### Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/uniqabhishek/furniture-website.git
   cd furniture-website
   ```
2. Open `index.html` in your web browser, or use a local static server:
   ```bash
   # Using Python:
   python -m http.server 3000
   ```
3. Visit `http://localhost:3000` in your browser.
